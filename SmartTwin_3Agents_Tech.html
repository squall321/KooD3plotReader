두 계층, 하나의 MCP 진입점

Smart Twin Flow — 운영

잡 제출 · 스케줄러 관리

Slurm을 조회·제어하고 임의 잡을 제출/취소하는 운영 계층. 대시보드 UI와 MCP(slurm-mcp)가 같은 backend REST를 씁니다.

  • 조회: squeue · sinfo · sacct · sdiag · sshare · sprio
  • 제어: hold/release/cancel · node drain/resume (dry_run 기본)
  • 제출: Path A(템플릿) · Path B(스크립트) · 취소
  • 인증: PAT(kst_) 발급 → Authorization 프록시
Smart Twin Cluster — 시뮬레이션

전·후처리 포함 HPC 캠페인

전처리(메시·시나리오)–솔브–후처리를 하나의 HPC 잡 흐름으로. 전각도 낙하·전위치 부분충격이 각각 DOE 드라이버로 자식 잡을 펼칩니다.

  • 전처리: KooMeshModifier · KooChainRun (Apptainer)
  • 솔브: LS-DYNA MPP (Apptainer, 라이선스 주입)
  • 후처리: koo_sphere_report · koo_impact_report
  • 제출: MCP smarttwin_submit / _scenario_options
자연어 지시→ MCP 도구→ backend REST(PAT)→ scenario/스크립트 생성→ Slurm 제출→ Apptainer 실행→ 결과 조회·다운로드
