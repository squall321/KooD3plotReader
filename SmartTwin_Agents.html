02 · 대화 재현

말로 지시하고, 클러스터가 응답한다

아래는 실제 MCP 세션에서 나온 응답을 그대로 옮긴 것입니다 — 미리보기(dry-run)로 생성된 scenario.json, 실제 제출 응답(job_id=799), 그리고 드라이버 로그.

slurm-mcp · streamable-httpadmin @ STC-X
엔지니어
폰 모델을 전각도 낙하로, fibonacci 100방향, 낙하높이 1m, 강체바닥으로 먼저 미리보기 해줘.
에이전트
▸ smarttwin_submit(sim_type=fullangle_drop, angle_preset=fibonacci-100, overrides={height:1000, drop_surface:RigidWall}, dry_run=true)
아래 scenario.json으로 26방향 대신 피보나치 100방향 낙하를 준비했습니다. 실제 제출은 dry_run=false로.

{
  "simulation_params": {
    "height": 1000,           // mm ← "1m"

  "scenarios": [{

      "source_type": "fibonacci_lattice",
      "fibonacci_lattice": { "num_directions": 100 }
    },
    "cumulative": { "mode_sequence": ["DROP"] }

}

Data Pipeline

모델링 에이전트와 연계된 데이터 축적

부품을 옮겨 배치를 바꾸는 모델링 에이전트가 만든 형상 변형과, 낙하·부분충격 에이전트가 돌린 해석 결과를 짝지어 DB에 쌓습니다. “배치 → 조건 → 응답”이 하나의 학습 레코드가 됩니다.

Graph Neural Network

접촉력 이력으로 리스크를 예측

부품 연결을 그래프로, 접촉력 이력을 신호로 삼는 GNN을 학습해, 시뮬레이션을 실행하기 전에 낙하 자세·충격 위치별 리스크를 사전 검토합니다. 위험 조합만 골라 정밀 해석으로 넘기는 스크리닝 루프입니다.
