# 기준량 확장 — 결정 노트

## 왜 |σ3| 로 순위를 매기지 않는가
σ3 은 부호가 있다. 인장 지배 영역은 σ3 ≈ 0 이거나 양수인데 |σ3| 로 매기면
압축 집중부와 인장 영역이 섞인다. 압축 핫스팟은 "가장 음수" 다. 오름차순이 맞다.

## 왜 `stress_max` 이름을 유지하는가
v30 SIF 와 field guide 가 이 이름으로 이미 나갔다. 이름을 바꾸면 소비자가 깨진다.
대신 파트 항목에 `direction` 을 넣어 "σ3 이면 `stress_max` 는 최솟값" 을 기계가 알 수 있게 한다.

## 왜 기준 하나짜리 시그니처를 유지하는가
`computeHotspotClusters` 는 단위 시험 대상이다. 다중 기준 오케스트레이션을 안에 넣으면
시험이 전부 다중 기준을 알아야 한다. 호출부(UnifiedAnalyzer)가 돌리는 게 단순하다.

## 중심 가중에 음수를 쓰면
`Σ w·x / Σ w` 에서 w 가 음수면 중심이 덩어리 밖으로 튄다. 심각도(hot 방향 양수화,
0 클램프)로 가중하고, 합이 0 이면 부피 가중으로 폴백한다(기존 폴백 재사용).

## NaN 표식
`-DBL_MAX` 는 "값 < 0 이면 미기록" 이라는 전제를 심었고 이게 부호 있는 기준에서 그대로
결함이 된다. NaN 은 어떤 비교에도 참이 되지 않아 실수로 선별될 수 없다.
