# 셸 지원 + 리포트 — 결정 노트

## 왜 층 중 '가장 뜨거운 층' 인가
굽힘이 있으면 최대 응력은 표면 적분점에서 난다. 중립면만 보면 굽힘 응력을 통째로 놓친다.
층 순서 해석(MAXINT>3 일 때 규격서 문구가 모호함)에 결과가 좌우되지 않는다는 장점도 있다.

## 왜 셸 대표 크기를 √면적 으로 바꾸는가
거리 임계 = factor × 대표 크기. 셸 부피(면적×두께)의 세제곱근은 두께가 얇을수록 작아져
면내 이웃 간격보다 임계가 작아진다 → 아무것도 안 묶인다. 군집은 면을 따라 일어나므로 면내 크기가 기준이다.

## 왜 솔리드는 그대로 두는가
기존 출력의 회귀 0 원칙. 다만 **얇은 솔리드**(PCB 를 1층 벽돌로 메시한 경우)에서도 같은 흩어짐이
생길 수 있다 — 실측 후 별도 보고한다.

## 강체 셸 압축
저장소 전체가 `NEL4×NV2D` 로 읽는다. DCOMP=2 덱이면 상태 크기부터 어긋나는 기존 결함일 수 있다.
셸 군집에서는 NDIM 5·7 이면 건너뛰고 경고한다. 전체 리더 수정은 범위 밖 — 보고만.

## 실증에서 나온 것 (2026-09-11)

### 층 순서 검증은 모델 물리를 가려야 한다
처음 세운 '중립 = 표면 평균' 검사는 case_shell 에서 1.68 로 크게 깨졌다. 층 값을 보니
안쪽 = 바깥쪽 = +0.0917, 중립 = −0.0627 — 두께 방향 **대칭(포물선) 열응력**이었다. 선형 가정이
틀렸을 뿐 오히려 층 0 만 튀는 것이 '층 0 = 중립면' 의 증거였다. 굽힘 지배인 case_01 에서는
7.6e-6 으로 성립했다.

### 변형률 오프셋은 같은 가정을 쓰는 numpy 로는 검증이 안 된다
그래서 후크 법칙을 썼다. 항복 전 17,440 표본에서 σ = E/(1−ν²)(εx+νεy) 가 성립하고
오프셋을 ±1 밀면 117~127% 로 붕괴 — 배치를 가정하지 않는 독립 근거.

### 얇은 솔리드 — 기존 결함
results/d3plot 파트 15(55×21×0.4 판)의 선별 11개가 맞닿은 두 무더기인데 덩어리 0.
임계 1.612 < 면내 간격 1.75. 셸용 면내 크기 정의를 육면체·쐐기 솔리드에도 적용했다.
정육면체·사면체는 수학적으로 불변.

### 평탄 분포
case_shell PCB 는 3,750 요소가 전부 같은 값(균일 온도 자유 휨). 상위 5% 가 동률 속 임의
부분집합이 되고, 우연히 붙은 몇 개가 '덩어리' 로 나와 진짜 핫스팟처럼 보였다.
JSON 에 `uniform` 을 명시하고 리포트는 순위표에서 뺀다. LLM 이 JSON 을 읽는 파이프라인에서도
같은 오독을 막기 위해 리포트가 아니라 분석기가 판정한다.
