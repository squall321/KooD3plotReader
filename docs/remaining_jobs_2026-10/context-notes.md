브랜치 커밋이 main 의 **조상**이 돼야 GitHub 이 PR #2 를 'merged' 로 닫는다. 리베이스하면

## PR #2 머지 — 충돌을 '어느 쪽이 맞나' 로 풀었다 (2026-10-17)

충돌 7곳(`json_report.py` 3 · `html_report.py` 4)이 전부 같은 모양이었다.
**main 이 더 나은 규약을 갖고 있었다** — PR 은 2026-09-04 판이고, 그 뒤 데이터 무결성
대수술이 자릿수와 다운샘플을 바꿨다.

| | PR 브랜치 (09-04) | main (대수술 이후) |
|---|---|---|
| 자릿수 | `round(v, 2)` | `round_keep_sig` — 유효숫자 유지 |
| 다운샘플 | 균등 간격 `step` | `extreme_indices` — 구간 극값 보존 |
| 없는 값 | 키를 늘 만듦(0.0 포함) | 키 자체를 안 만듦 |

그래서 **main 구조를 지키고 PR 의 새 키만 그 규약에 맞춰 얹었다.** 별칭은 실제로 실린
값에만 건다 — `if "peak_strain" in pd` 처럼. 미계측인데 별칭만 생기면 안 된다.

**가장 위험했던 것은 자동 병합된 부분이다.** `_series_payload` 는 충돌이 안 나서 PR 판이
그대로 들어왔는데, 그 함수가 **옛 규약**(균등 다운샘플 + `round`)이었다. 새로 나가는
시계열 5종만 이미 고친 결함으로 되돌아갈 뻔했다. 충돌난 곳만 보고 넘겼으면 못 봤다.

`_series_payload` 는 `json_report` 것을 `html_report` 가 **import 해 쓴다.** PR 은 두
파일에 같은 함수를 복제했는데, 그러면 한쪽만 고쳐져 어긋난다 — 이 저장소가 반복해 밟은
함정이라(핫스팟 기준 목록이 C++·파이썬 두 곳에 있던 것) 한 곳으로 모았다.
