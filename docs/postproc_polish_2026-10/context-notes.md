# 후처리 마감 보완 — 결정과 근거

## 2026-10-18 — ①~④ 실행 중 내린 결정

### ① null 을 0 으로 세던 것이 예외보다 나빴다
눈에 보인 것은 탭 3개가 죽는 `null.toFixed()` 였다. 고치면서 안 것은 `reduce`·
`Math.max` 가 **null 을 0 으로 세어 평균이 조용히 틀렸다**는 쪽이다. 절반이
미계측인 파트에서 평균이 112.0 → 56.0 으로 깎였고 화면에는 멀쩡한 숫자가 떴다.
죽는 쪽은 보이기라도 한다.

payload 를 고치지 않고 읽는 쪽에 가드를 둔 이유 — `html_report` 는 `json_report`
와 달리 **키를 항상 만들고 값에 null 을 넣는다.** 화면 JS 49곳이 그 키가 있다고
보고 쓰는 구조라, 키를 빼면 그 49곳이 전부 `undefined` 를 읽는다. 이 구조는
`be9d2b0` 이전부터 그랬다 (이번 PR 머지가 만든 것이 아니다).

**0 은 값이다.** `isNum(0) === true` 를 시험으로 못박았다. '응력 0' 과
'못 쟀다' 를 섞으면 그 구분이 숫자 안으로 사라진다.

### ② 경고가 아니라 적용으로 고쳤다
계획은 "최소한 경고" 였다. 코드를 보니 `run_single` 은 맨 앞에서
`_apply_config_to_args` 를 부르고 `run_batch` 만 안 부른다 — 설계상 batch 가
설정을 안 받아야 할 이유가 없고, `__main__.py` 903줄이 **이미 같은 부류의
복제 함정을 경고하고 있었다.** 그래서 경고 대신 single 과 같게 적용한다.

batch 의 `path` 는 필수 위치인자라 설정 파일의 `d3plot:` 은 여전히 안 쓰인다.
이건 조용히 버리면 "설정에 적은 경로를 돌았겠지" 로 오해하므로 한 줄 알린다.

### ③(a) 상대경로 기준을 CWD 에서 출력 폴더로
보고서 탭 11 이 만들어 주는 YAML 이 `output_dir: "renders/section_view_..."` 로
상대 경로다. 전에는 CWD 기준이라 실행한 자리에 쏟아졌다 (저장소 루트 PNG 401개).
더 나쁜 것은 **보고서가 `<output_directory>/renders` 만 훑는다**는 점이다 —
출력 폴더에서 실행하지 않으면 렌더가 만들어지고도 보고서에 안 붙었다.
`part_section_renders` 는 이미 출력 폴더 기준이었다. 두 경로가 달랐던 것이 결함.

`output_directory` 가 비면 예전대로 CWD 기준 — 규칙을 모르는 호출자를 깨지 않는다.

### ③(b) 문서화에 그치지 않고 선택지를 넣었다
계획은 "최소한 문서화" 였는데, 실덱으로 재 보니 문서로 넘길 일이 아니었다.
AABB 가운데 z=-10.025, σ_vm 피크 z=-2.300 — 7.7mm 차이로 **단면이 거의 빈
화면**이 나오는데 컬러바는 그대로 310.4 를 띄운다. 보는 사람은 "여긴 괜찮네" 로
읽는다. 그림이 틀린 게 아니라 **그림이 거짓말을 한다.**

기본값을 `peak` 로 바꾸지 않은 이유 — 기존 사용자의 그림이 조용히 바뀐다.
AABB 가 피크를 비켜갈 때 경고를 띄우는 것도 생각했지만 피크 탐색이 **+4.5초**
(400상태 덱)라 기본 경로에 강제로 넣을 비용이 아니다. 대신 CLI `--help` 에
노출했다 — 숨은 YAML 키로만 두면 없는 것과 같다.

절점평균으로 피크를 고른 이유: 그게 **화면에 그려지는 값**이다. 요소 생값으로
고르면 그림의 최대와 어긋난 자리를 자른다.

### ④ 캔버스에 호버가 없던 것이 왜 결함인가
Plotly 뷰어에는 호버가 있다 (그 코드 주석이 "Plotly 를 고르는 이유가 이것이다"
라고 적고 있다). 그런데 **Plotly 쪽은 값 상위 `HS3D_PLOTLY_MAX` 개로 잘린다.**
전수를 보는 쪽이 캔버스인데 거기에 호버가 없으면, 26각도 651군집 중 라벨
16개만 읽히고 나머지 635개는 "보이지만 무엇인지 모르는 공" 이다.

컨투어 모드에서도 집히게 뒀다. 버블이 안 보여도 "이 붉은 자리를 만드는 게
무엇인가" 가 바로 그때 묻는 질문이다.

`HS3D.pick` 에 **화면 좌표 그대로** 보관한다. 다시 투영하면 회전·줌과 어긋나
엉뚱한 군집을 집는다. 파트를 전부 끄는 분기에서 `pick` 을 비우는 것도 같은
이유 — 옛 목록이 남으면 빈 화면에서 툴팁이 뜬다.
