## 착수 전 (2026-10-26~27, 상류와 7회 왕복)
설계 확정 경위는 [design.md](design.md) 에 있다. 요지만 —
- (3) 상류 원안은 **메모리를 못 줄인다**. 84.7 GB 는 캐시 생성이 아니라
  `loader.py:1077-1081` 의 **최종 누적분**이다. 2패스로 바꿔 5.3 GB.
- (4) **환산하지 않는다.** 안전계수는 비율이라 덱 단위끼리면 약분되고,
  단위 검출은 미검출 경로가 넷이라 판정에 끌어들이면 1e6 배 오류가 된다.
- `limits` 를 측도 부재로 조용히 빼면 안전율이 **위험한 쪽**으로 틀린다.
- 내가 한 `metavar` 경고는 **틀렸다** — 철회함 (`b3c9dc0`).

## (2) 착수 — 탈락 사유 수집 방식 (2026-10-28)

### 탈락 경로는 둘뿐이다
`load_simulation_result` 의 `return None` 두 자리 —
- `loader.py:651` `load_dropset()` 이 None (= `DropSet.json` 없음)
- `loader.py:657` `analysis_result.json` 없음

호출부(`loader.py:999-1007`)는 `if sr is not None` 으로 **조용히 버린다.**
M3_P2 샤드의 "Loaded 0 results" 가 이것이었다.

### 호출부에서 사유를 다시 판정하지 않는다
`sr is None` 일 때 호출부가 같은 조건을 다시 검사하는 방법도 있지만 **안 쓴다.**
`__main__.py:903` 이 경고하는 복제 함정과 같은 부류다 — 조건이 한쪽만 바뀌면
사유가 조용히 틀린다. 대신 `load_simulation_result` 에 **선택 인자**로 사유
수집기를 넘긴다. 안 넘기는 호출자는 영향 없다(현재 호출부는 한 곳뿐이라
확인했다).

### `load_dropset` 의 `json.load` 를 감싼다
지금은 `try` 가 없어 **깨진 DropSet.json 하나가 979런 적재를 통째로 죽인다.**
이건 조용한 실패는 아니지만(터지니까), 자동화에서는 한 파일 때문에 캠페인이
날아가는 게 더 비싸다. 깨짐도 **사유로 세고** 나머지는 계속 읽는다.
— 이 변경은 "탈락 사유를 사실대로 말한다" 는 (2)의 목적 안에 있다.

### `Loaded N results` 를 먼저 찍는다
상류 셸이 이 줄을 보고 없으면 경고, 0 이면 자기도 rc 3 을 낸다.
exit 3 을 넣되 **그 줄이 먼저** 나가야 한다 — 순서가 뒤집히면 셸이 "줄이 없다"
경고를 내고 우리 사유는 묻힌다.

## 2026-10-31 — 커밋 단위 실수와 그 여파

`2eeb7c0`(캐시 스키마 4 · 화면 안전율)을 올리며 `git add loader.py` 를 했는데
**그 파일에 (3)의 2패스 축약이 이미 들어 있었다.** 커밋 메시지에는 둘만 적었고
실제로는 셋이 나갔다. bf 가 그 판으로 배포를 청한 뒤에야 알았다.

확인 — `origin/main e6cce7f` 를 worktree 로 떠서 실행: sphere 시험 160 통과,
mini26 실데이터 흐름 적재 정상(`시계열 보유 2/2`), 예외 0, exit 0.
`analyze()` 가 `parallel_runs` 를 안 넘기므로 **순차로만** 돈다(기본 1) —
기능은 안전하고 메모리만 줄어든다.

**다만 상류 사이징과 어긋난다.** `sphere_report.sh` 는 `--help` 의
`--parallel-runs` 유무로 메모리 공식을 고르는데, 이번 판에는 없으니 옛 공식
(32 + 0.10×N GB, 979런 ≈ 130 GB)으로 잡는다. 실제로는 2패스 덕에 훨씬 적게
쓰므로 **과다 할당**이다 — 위험하진 않지만 큰 잡이 대기에 오래 걸린다.
bf 에게 릴리스 노트 보완과 상류 통보를 요청했다.

**교훈: 한 파일에 두 작업이 들어 있을 때 `git add <파일>` 은 위험하다.**
앞으로 `git add -p` 로 조각을 보고 올린다. 이 저장소는 세션 둘이 작업트리를
공유하므로, 내 미커밋 변경이 남의 커밋·푸시에 묻어 나갈 여지가 더 크다.

**남은 배선**(`__main__.py`·`analyzer.py` 의 `-j/--parallel-runs`)은 지금 올리지
않는다. 올리면 `--help` 에 옵션이 생겨 상류가 새 사이징으로 바뀌는데 **워커
RSS 실측값이 아직 없다**(mini26 DropSet 삭제로 런이 2개). 측정 뒤 v44 로 함께 낸다.
