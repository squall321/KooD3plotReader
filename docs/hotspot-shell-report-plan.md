## 2. 셸 데이터 배치 (ls-dyna_database.txt 1918–2075)

요소당 워드 = `MAXINT × P + 8·IOSHL(3) + 4·IOSHL(4) + 12·ISTRN`, `P = 6·IOSHL(1) + IOSHL(2) + NEIPS`.

| 구간 | 오프셋 (요소 시작 기준) | 내용 |
|---|---|---|
| 층 k (k = 0..MAXINT−1) | `k·P` | σ 6성분 · 유효소성변형률 · NEIPS 이력 |
| 합력 | `MAXINT·P` | 8워드 (IOSHL(3)) |
| 두께 등 | `MAXINT·P + 8·IOSHL(3)` | **두께**, 요소변수 2 (IOSHL(4)) |
| 변형률 | `… + 3·IOSHL(4)` | 안쪽 면 6 · 바깥쪽 면 6 (ISTRN) |
| 내부에너지 | 끝 | IOSHL(4) |

- 층 0·1·2 = 중립면·안쪽 면·바깥쪽 면 (MAXINT = 3, NUMDS ≥ 0 일 때). 굽힘 최대는 표면이다.
- 두꺼운 셸: `MAXINT × P + 12·ISTRN (+1 TSHENG)`, 변형률은 `MAXINT·P` 부터.
- 🔴 `DCOMP=2`(헤더 NDIM 5·7)면 강체 셸 데이터가 **압축**돼 인덱스가 어긋난다 — 셸 군집을 건너뛰고 경고.

## 3. 설계

- **요소값** — 층마다 기준값을 구해 **가장 뜨거운 층**을 취한다(von Mises·σ1 최대, σ3 최소).
  층 순서 해석에 의존하지 않는다. 극값이 난 층 번호(`peak_layer`)도 남긴다.
- **짝 변형률** — 극값 층이 안쪽/바깥쪽이면 그 면, 중립면이면 두 면 텐서의 평균(Kirchhoff 선형 분포),
  그 외면 두 면 중 뜨거운 쪽.
- **기하**
  - 셸: 등매개 쌍선형 곡면 면적·도심 `A = ∫|x_ξ × x_η|`. 평면 사각형·삼각형은 2×2 가우스로 정확, 뒤틀린 사각형은 고차 가우스.
  - 가중: 면적 × 두께(초기 상태 두께 워드). 두께가 없으면 면적.
  - 두꺼운 셸: 솔리드와 같은 등매개 부피·도심.
- **대표 요소 크기** — 군집 거리 임계의 기준.
  - 솔리드: 기존 그대로 `∛(부피 중앙값)` (회귀 0).
  - 셸: `√(면적 중앙값)`.
  - 두꺼운 셸: `√(부피 / 최소 대면간 거리)` 의 중앙값 — 면내 크기. `∛V` 를 쓰면 얇은 요소에서 임계가 면내 간격보다 작아져 **이웃이 안 묶이고 전부 흩어진다**.
- **출력** — 파트 항목에 `element_type`, `weight_measure`, `bbox_min/max`(초기 형상), 셸이면 덩어리에 `area`·`peak_layer`.

## 4. 리포트

- 새 탭 "핫스팟 군집": 기준·파트 선택, 덩어리 표(순위·중심·파트 내 상대위치·반경·평균/극값·짝 변형률·피크 요소/시각/층), 파트 경계상자 안에 덩어리를 실제 반경의 구로 그린 3D 뷰.
- 파트 내 상대위치는 경계상자 기준 백분율 — "파트의 어느 쪽" 을 바로 읽게 한다.

## 5. 검증

1. 셸 기하 — 해석해(사각형·사다리꼴·삼각형), 뒤틀린 사각형 수렴.
2. 오프셋 — (a) 두께 워드 = 입력 덱 `*SECTION_SHELL` T1, (b) 탄성 PCB 에서 중립면 = (안쪽+바깥쪽)/2, (c) numpy 로 층별 극값·시각·층·짝변형률 대조.
3. 합성 셸/두꺼운 셸 격자 군집 해석 답.
4. 솔리드 골든 불변 (신규 필드 제외).
5. 리포트 — 실제 HTML 을 브라우저로 열어 탭·표·3D 확인.
